Bitecho Relay Ferry

Ferry opaque blobs between an offline light node and the HTTP Gateway Relay (/relay/v1/*). The node signs everything locally (shuttle.cjs); this page only moves bytes. Nothing here holds a key. Poll/ack blobs are single-use and expire after 5 minutes — generate fresh, ferry immediately.

Multi-node note (measured 2026-11-12): the relay ring is per-node in-memory state and bitecho.org load-balances across ns1..ns3, so a poll that lands on another node than the send may return empty — click Poll again (each click may reach a different node). Opening this page at ns1.bitecho.org/relay.html pins send and poll to one node. The relay needs shared state or sticky routing before this page is relied on at the bare bitecho.org URL.

1. Send an envelope

Paste the envelope_hex from shuttle.cjs export-offer, export-accept or export-send. Check the character count and SHA-256 prefix match the node before clicking send.
